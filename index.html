01 / THE PROTOCOL

From information to evidence.

Vortex does not store files, models, or documents. It records minimal cryptographic fingerprints so anyone can verify integrity, authorship, and history.

#

LOCAL HASH

The file stays with you. Only its mathematical fingerprint is prepared for registration.

◇

COMMITMENT

Millions of records can be condensed into a single 32-byte Merkle root.

V

PoW INCLUSION

The commitment enters a Vortex block with an inclusion proof and accumulated work.

✓

PORTABLE RECEIPT

Offline verification with no account, company, server, or mandatory node. Evidence that outlives its issuer.

03 / ARCHITECTURE

Built to fail clearly.

Determinism, explicit bounds, and auditable recovery form the core. Post-quantum and AI research remain separate from consensus until accepted security models exist.

CORE / RAM-FIRST

FAST STATE.
DURABLE MEMORY.

Deterministic kernel, UTXO model, state roots, write-ahead log, authenticated snapshots, and crash recovery.

NETWORK // 01

Authenticated transport

Noise XX over TCP, identities bound to the handshake, and peer synchronization.

CONSENSUS // 02

Proof-of-Work

Block admission, accumulated-work fork choice, and auditable reorganization.

DEFENCE // 03

Explicit bounds

Mempool, relay, connections, and adversarial behavior tested under defined budgets.

AGILITY // 04

Post-quantum future

Cryptographic agility and hybrid migration are research goals — not current claims.

04 / EXECUTION VECTOR

The future, in order.

Each layer advances only after the previous one produces real evidence. No selling imaginary speed, future decentralization, or post-quantum security before its time.
